# Versioning

Object Proximity Analysis uses semantic versioning.

- Patch releases fix behaviour without changing valid public API calls.
- Minor releases add backward-compatible measurements, options, or outputs.
- Major releases may change scientific definitions or public API contracts.

`0.x` releases are developmental. Scientific definitions and output columns can
still change before `1.0.0`, and each such change must be recorded in
`CHANGELOG.md`.
